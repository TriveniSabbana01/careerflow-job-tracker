# CareerFlow – Job Application Tracker

CareerFlow is a responsive job application tracking web application designed to help users organize and manage their job search process in one place.

## Features

- Add and manage job applications
- Track applications by status
- Kanban-style job application board
- Search and filter applications
- Track interviews and offers
- View application statistics and response rate
- Export application data
- Light/Dark mode
- Responsive user interface
- Local storage for saving application data

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- Amazon S3 for static website hosting

## Project Structure

- `index.html` – Main application interface
- `styles.css` – Application styling
- `js/` – JavaScript modules for application logic, validation, storage, drag-and-drop, and DOM operations

## Live Demo

Deployed using Amazon S3 Static Website Hosting.

## Purpose

This project was developed to practice frontend development, UI/UX design principles, JavaScript functionality, and cloud-based static website deployment using AWS S3.
